# Иллюстрированные обложки меню

Все 136 игр имеют явную обложку в `src/frontend/data/menuCovers.ts`. Раньше 126 игр использовали MDI fallback. Теперь `MenuCover.vue` рисует только изображения: 86 обложек используют существующие ресурсы, ещё 50 — новые отдельные иллюстрации. Семь папок и две карточки главной сохраняют прежние рисунки.

Обложки общие для меню специалиста и самостоятельного меню, а также для Sunny Meadow, Paper Story и Toy World. Размер карточек, подписи, фильтры, доступность игр и обработчики ввода сохранены. Изображения декоративные (`aria-hidden`, пустой alt, `pointer-events: none`); доступное имя задаёт карточка.

## Ресурсы

- Новые иллюстрации: `public/images/menu-covers/<game-id>.webp`.
- Генерация: встроенный imagegen, прозрачный фон, контуры и мягкие тени по существующим сове и воздушному змею. Полные задания: `public/images/menu-covers/generation.json`.
- Доставка: максимум 512 × 512, WebP quality 0.94, пропорции и прозрачность сохранены. Суммарно 2 533 066 байт. Размеры, SHA-256 исходных PNG и WebP: `public/images/menu-covers/encoding.json`.
- Исходные сгенерированные PNG сохраняются отдельно от репозитория. Персонажи и изображения внутри игр не заменяются.
- Все 643 существующих файла `public/images` проверены по SHA-256 и сохранены без изменений.

Составные персонажи (бабочка, светлячок, медуза, робот) собраны из существующих частей. Пути с расширениями разрешаются через `resolvePublicAssetUrl`, поэтому PNG, JPG и WebP работают и в Electron `file://`. Неизвестная будущая игра получает рисунок книги; тест требует явного покрытия всех игр текущего реестра.

## Добавление обложки

1. Использовать существующий целый рисунок или добавить отдельный ресурс в `menu-covers`.
2. Добавить запись с ID из `games.ts` в `gameMenuCovers`.
3. Проверить миниатюру в обоих меню, трёх темах и Electron. Для деталей персонажа использовать композицию, а не отдельный фрагмент.
4. Запустить `npm run typecheck`, `npm run lint:adaptive-layout`, `npm run test:unit` и `npm run build`.

Тест `scripts/ci/menu-covers.test.mjs` проверяет точное соответствие реестру, наличие всех ресурсов и иллюстрированный fallback.
