# Оформление приложения

Sunny Meadow включён по умолчанию. Paper Story и Toy World выбираются кнопкой
«Оформление» в меню специалиста или самостоятельном меню. Выбор применяется сразу
и сохраняется локально. На главной и в играх отдельного переключателя нет.

## Где находятся стили

| Уровень | Источник | Назначение |
| --- | --- | --- |
| Контракт темы | `src/frontend/themes/index.ts` | Три палитры Vuetify, контуры, тени, радиусы и палитры окружения |
| Состояние | `src/frontend/core/themeSettings.ts` | Сохранение, проверка ID, CSS-переменные и текущая Canvas-палитра |
| Vuetify | `src/frontend/plugins/vuetify.ts` | Регистрация и синхронизация тем, общие defaults |
| Общий CSS | `src/frontend/styles/appearance.css` | Шрифт, карточки, кнопки, состояния, обои меню |
| Страницы | `src/frontend/pages/` | Адаптивная компоновка главной и двух меню |
| Игровая оболочка | `src/frontend/components/game/GamePageShell.vue` | Семантический фон через CSS-переменные |
| DOM и SVG | Локальные стили игр | Декоративные поверхности через переменные темы |
| Canvas | Игровые render-функции и `scene.ts` | `scenePalette(kind)` или переданная палитра |

Ключ настройки — `linka-appearance-theme`. Неизвестное значение возвращает Sunny
Meadow. При недоступном storage тема работает до закрытия приложения. Инициализация
происходит до монтирования Vue, включая аудиодиалог. Обновление палитры не меняет
ключ игрового компонента и не пересоздаёт сессию.

## Новая сцена

1. Выбрать окружение из `SceneKind`: например, `meadow`, `water`, `night` или `paper`.
2. Для DOM использовать `var(--linka-scene-meadow)`; отдельные цвета доступны как
   `--linka-scene-meadow-0`, `-1`, `-2` и `-base`.
3. Для Canvas получать `scenePalette("meadow")` при рисовании. В вынесенный renderer
   передавать палитру аргументом; не сохранять её однократно при импорте модуля.
4. Сохранять исходные позиции gradient stops, размеры объектов и зоны взгляда.
5. Учебные цвета, сигналы успеха/ошибки и изображения не подменять декоративными
   токенами. Ночные, подводные и космические сцены сохраняют свой смысл.
6. Проверить все три темы в Electron, мышь, gaze geometry и нижнюю границу окна.

## Персонажи и ресурсы

Смешанный набор уже заменённых и ещё не заменённых персонажей сохранён из коммита
`73d3fd3`. Все 640 существовавших файлов `public/images` совпадают по SHA-256 с
исходной рабочей копией. Новые картинки — только три отдельных фона в
`public/images/themes/<id>/background.png`. Обложки меню используют имеющиеся арты;
картинки учебных заданий не перекрашиваются.

Фоны созданы с помощью imagegen по согласованным направлениям: солнечный луг с
ромашками, бумажная история и мир игрушек. Задание генерации: фон без надписей,
интерфейса, персонажей и игровых объектов, со свободным центром под элементы UI.
Nunito с кириллицей поставляется локально вместе с SIL OFL; сеть для тем не нужна.

## Доступность выбора

`ThemeChooser.vue` использует тот же `GameDwellButton`, что игры. Выбранная тема
отмечена текстом, галочкой и `aria-pressed`. Открытый диалог отключает игровые
цели самостоятельного меню. Его цели имеют повышенный приоритет и нулевой
hit-padding; активное выделение не масштабирует видимую кнопку относительно зоны.
Прозрачные цели (`color="transparent"`) получают класс `dwell-button--transparent`
и исключены из общих рамок и теней: их видимая фигура задаётся самой игрой.
На узком экране показывается одно превью с крупными кнопками перехода. Кнопка
«Готово» также доступна удержанием взгляда. Общий cooldown ввода сохранён.

## Проверка

```sh
npm run typecheck
npm run lint:adaptive-layout
npm run test:unit
npm run build
npm run smoke:renderer-assets
npm run audit:themes -- --port=9223 --base-url=http://127.0.0.1:5174 --output=.qa/all-theme-routes.json
```

Последняя команда требует уже запущенный настоящий Electron с отдельным тестовым
профилем. Она меняет настройку темы этого профиля, открывает 136 игр во всех темах
и запускает режим в играх с предварительным выбором. Проверяет маршрут, тему,
наличие HUD, изображения и исключения renderer. Это smoke загрузки, а не прохождение
каждого задания. Проверку устройства Tobii он не заменяет.

Результаты и ограничения приёмки: [отчёт](tests/2026-10-31/themes.md).
