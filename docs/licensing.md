# Лицензирование «Линка. играй»

## Собственный код

Исходный код, разработанный для LINKa Plays Electron, распространяется на условиях
GNU General Public License версии 3 или, по выбору получателя, любой более поздней версии.
Идентификатор SPDX: `GPL-3.0-or-later`. Полный текст лицензии находится в файле `LICENSE`
в корне репозитория; в установленной Electron-сборке — в каталоге ресурсов рядом с `LICENSING.md`.

Программу можно использовать, изучать, изменять и создавать форки, в том числе в коммерческих целях.
При распространении копий и производных версий нужно соблюдать GPL: сохранять правовые
уведомления и текст лицензии, обозначать изменения и предоставлять получателям соответствующий
исходный код на условиях GPL. Лицензия не требует публиковать личные изменения, которые
не распространяются другим лицам.

Программа предоставляется без гарантий в пределах, установленных разделами 15–16 GPLv3.

## Сторонние компоненты и материалы

GPL для собственного кода проекта не заменяет лицензии сторонних библиотек, SDK, шрифтов,
изображений и аудиозаписей и не предоставляет отсутствующих разрешений на их распространение.
Такие материалы не перелицензируются этим документом. При сборке нужно сохранять их
собственные тексты лицензий и уведомления. Для изображений и аудиозаписей, у которых нет
отдельного разрешения, этот документ новую лицензию не устанавливает.

Проверенные условия отдельных поставляемых материалов:

- `public/audio/sfx/bells/soft-bell.ogg` — CC0; сохранить соседний файл
  `soft-bell.LICENSE.txt` с авторством и источником.
- `public/audio/sfx/sound-source/` — шесть MP3 из Mixkit; источники записаны в README
  этого каталога. Они регулируются [Mixkit Sound Effects Free License](https://mixkit.co/license/modal/sfxFree/),
  а не GPL. Эта лицензия разрешает использование звуков в готовых играх, но запрещает
  перераспространение отдельных файлов, в том числе вместе с исходниками.
- `vendor/linkasu-tobii-electron-0.2.16.tgz` — в `package/package.json` архива указано
  `UNLICENSED`; текста лицензии для пакета нет. В архив также входят `EyeLog.exe` и DLL Tobii,
  условия распространения которых нужно проверить отдельно. Декларация GPL в корне
  приложения не меняет условия этого архива.
- npm-зависимости используют собственные лицензии; сведения в `package-lock.json`
  служат указателем, а полные условия нужно брать из поставляемых пакетов.

## Перед первым GPL-релизом

Добавление GPL для собственного кода не подтверждает автоматически совместимость всех
компонентов установленного приложения. Перед выпуском нужно:

1. Подтвердить право лицензировать существующие вклады участников на условиях GPL-3.0-or-later.
2. Установить условия распространения Tobii-модуля и встроенных DLL и проверить совместимость
   выбранного способа их объединения с GPL.
3. Заменить звуки Mixkit на собственные или совместимые свободные записи либо получить
   отдельное разрешение на распространение вместе с исходниками. Простого исключения
   этих звуков из GPL недостаточно для разрешения их раздачи в открытом репозитории.
4. Установить права и условия распространения остальных изображений и аудиозаписей.

Полная GPL-совместимость готовой сборки до выполнения этих пунктов не заявляется.
