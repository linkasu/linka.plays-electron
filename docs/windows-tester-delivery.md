# Доставка Windows-приложения для проверки с Tobii

## Открыть игру из таблицы

На листе «Правки» колонка C должна вести на
`https://linkasu.github.io/linka.plays-electron/open.html?game=<id>`.
Страница показывает название игры, ссылку «Открыть в приложении» и последнюю
опубликованную Windows-сборку. Кнопка вызывает `linka-play://game/<id>`:
Windows запускает Linka Play или передаёт адрес уже открытому экземпляру.
Браузер может запросить разрешение на запуск приложения. Без установленной
программы нужно скачать установщик, запустить её и повторить нажатие.

`play.html`, `tests.html` и PR-превью — браузерные версии **без Tobii**; их
ссылки не следует ставить в колонку C. PR-ссылки разработчиков в колонке P
можно оставить.

## Публикация

С версии 3.0.0 публичный Windows-комплект включает сохранённый отдельный
лаунчер и Electron-игры. Требуется Windows 10 (1809+) / 11 x64. Установка
поверх Unity 2.0.0 сохраняет каталог и ярлыки на лаунчер. Версия приложения,
установщика и обоих `version.json` совпадает и состоит только из чисел.

Обновления Windows предлагает лаунчер; скачивание и установка Electron-updater
отключены, в том числе в тестовом режиме. Уже установленную тестовую Electron
0.1.x нужно однократно обновить вручную полным комплектом. Новый Inno Setup не
публикуется как `latest`/NSIS-update для старых Electron-updater. macOS в этот
переход не входит. Подробный порядок — [windows-release.md](windows-release.md).

`.github/workflows/windows-main-release.yml` остаётся отдельным тестовым потоком
0.1.23-beta; он не переключает публичные установщики и манифесты сайта.

Релизные артефакты и список версий: https://github.com/linkasu/linka.plays-electron/releases.
Публичная страница `https://linka.su/play` использует прежний URL
`https://linka.su/linkaplay/linkaplaysetup.exe`. Зеркало
`https://linka.su/dist/linka.plays/linka.plays.setup.exe` содержит тот же комплект.

## Проверка

1. CI: `npm run typecheck`, `npm run test:unit`, `npm run build:web`.
2. Windows: после установки проверить регистрацию `linka-play`, холодный
   запуск `linka-play://game/space-orbit` и переход уже открытого окна на
   `linka-play://game/gaze-maze` через системный протокол.
3. В отчёте `smoke:packaged-window` проверить маршрут и доступность
   `window.linkaTobii` в упакованном окне. Этот smoke работает с
   `LINKA_NO_TOBII=1` и **не доказывает работу физического устройства**.
4. На компьютере тестировщицы установить пакет, открыть строку таблицы и
   выполнить действие взглядом. Сообщить версию и короткий SHA со стартового
   экрана, если Tobii не отвечает.

Перед массовой заменой ссылок сохранить копию листа, проверить одну ссылку,
а после замены сверить все 136 игровых адресов. Если переход не работает,
вернуть ссылки из копии. Выпущенную плохую версию исправляют
новым пакетом с **более высокой** версией, не подменой старого файла.

Таблица редактируется через обычный интерфейс Google Sheets. Резервная копия
файла хранится отдельно на Диске с датой в названии. При замене ссылок сверять
каждую строку с ID игры в колонке R; служебную колонку P не менять.

Оба зеркала под `/home/aacidov/linka-docker/wordpress/` публикует
`scripts/publish-windows-release.mjs` по точному стабильному тегу, с проверкой
SHA-256, резервной копией и заменой манифестов после готовых установщиков.
Не запускать прежний `update.js`, который выбирал GitHub `releases/latest`.
