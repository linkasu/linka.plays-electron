# Обложки меню

50 иллюстраций созданы встроенным imagegen для меню LINKa Plays. Они не заменяют картинки внутри игр. Полные задания и ссылки на стилевые референсы — в `generation.json`, размеры и SHA-256 — в `encoding.json`.

WebP: максимум 512 × 512, качество 0.94, прозрачный фон. Подключение и составные обложки — в `src/frontend/data/menuCovers.ts`. Правила и проверка описаны в `docs/menu-covers.md`.
